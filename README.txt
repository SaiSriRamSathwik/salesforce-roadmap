SALESFORCE ROADMAP — LIGHT / MODERN EDITION

This package replaces the previous app version. Upload these files to the ROOT of the same GitHub repository:
- index.html
- manifest.webmanifest
- sw.js

New interface:
- Bright light background and white elevated cards
- Blue/green progress dashboard and modern mobile layout
- Per-task editable start/end time controls
- Quick time presets: Morning (9 AM–12 PM), Afternoon (1–4 PM), Evening (5–7 PM), Night (7:30–9 PM), and 1-hour focus
- Custom time entry
- Duration display
- Edit original roadmap task text
- Completion tracking and local saving
- Added cache version so browsers can update the previous version

To deploy:
1. Extract this ZIP.
2. In the existing GitHub repo, choose Add file > Upload files.
3. Upload these three files to the repository root, replacing the existing files.
4. Commit changes.
5. Wait for GitHub Pages deployment to finish.
6. On iPhone, open the site in Safari, refresh it, then close/reopen the Home Screen app if needed.

Time presets and task edits are local to this browser/device. Background notifications and cross-device cloud sync are not included.
